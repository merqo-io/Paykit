# UI primitives

CLI-managed shadcn primitives used by Paykit feature components: badge, button, checkbox, dialog, input, label, radio-group, skeleton, textarea and tooltip. Keep generated implementations close to upstream. Account menus and support drawers are supplied by @merqo/ui. Radio groups serve payment setup; the checkbox serves the inquiry form's terms box and its on/off setting; skeletons serve loading states. Remove unused complete primitives instead of maintaining dormant copies.
